# Direct preview connection
Use a team-scoped, short-lived Vercel access token from your account token settings. Store it as encrypted server-only DEVHQ_PREVIEW_VERCEL_TOKEN for Preview, branch prototype/devhq-launch-feature-management, on the existing teach-arcade-development-hq project. Do not paste the credential in chat, logs, or source. Rebuild that HQ branch. The admin-only Launch page checks the existing public and HQ projects and dedicated config before enabling setup. CONNECT PREVIEW creates only read credentials and branch-specific public pilot environment variables, without overwriting existing variables or deploying. On a partial or uncertain result inspect the existing keys and store token list; do not blindly retry. Rebuild the public pilot once after setup, then verify a block/unblock without redeploy. Publishing remains restricted to the dedicated store and explicit PUBLISH PREVIEW, and requires the public preview keys to exist. No production controls. Revoke the token when not needed or rotate it at expiry. The token's upstream permissions may be broader than the application allowlist; keep it private.
