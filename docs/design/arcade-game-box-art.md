# Arcade Review Games — Classic Game Box

Approved direction: black-and-gold packaging from concept A, with the simpler flat arcade illustration style from concept C. Applies to all 18 games on `/arcade-review-games/`.

Each cover uses a charcoal frame, gold rules, cream brand label, gold/cream pixel title, square illustration window, and small controller badge. Packaging is HTML/CSS so titles remain crisp and consistent at every size. Decorative cover text is hidden from assistive technology; existing descriptive link labels and game headings remain available.

The responsive shelf shows three columns on desktop, two on tablets, and one on small screens. Game descriptions, badges, links and gameplay are preserved.

Artwork: 18 original AI-generated scenes, delivered as square 384px and 768px WebP images. Built-in image generation used the approved combined mockup as a style reference. Prompts are recorded in `arcade-game-box-prompts.json`. Broad color regions, restrained pixel shading and distinct motifs keep the artwork readable. Previous Flat Arcade assets are retained.

Validation: full static build; exact preservation of article bodies, anchor attributes, metadata and scripts; decoded WebP dimensions; browser preview covering loading, layout and keyboard focus.
