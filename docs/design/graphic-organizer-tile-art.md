# Graphic Organizers — Flat Arcade

All 12 template tiles use the approved Flat Arcade style with Soft Mint (`#DDF3E6`) backgrounds and white copy areas. The Visual Timeline Creator card reuses the matching Teacher Tools illustration, making 13 illustrated cards on the collection page.

The new AI-created artwork uses simple blue/teal/gold worksheet motifs with bold navy outlines. These are decorative thumbnails rather than usable worksheet previews. Transparent sources are exported as 384×256 and 768×512 WebPs; CSS supplies the exact common background.

Template titles, descriptions, tags, and destinations remain HTML. Empty image alt text avoids repeating the card name. Each card has one keyboard focus target; nested decorative CTA buttons are rendered as spans. No template editor or PDF behavior changes.

The manifest records prompts and asset mappings. The collection uses a responsive 3/2/1-column grid.
