# Homepage — Classic Marquee

Previous design, superseded by [Bold & Simple](homepage-bold-simple.md). Assets are retained for reference.

Implements approved banner concept A: deep navy, a beveled cabinet-style frame, restrained gold rules, cream block headline and an original arcade joystick illustration. The headline, brand, subtitle and both links remain real HTML; only the decorative joystick uses generated artwork.

The existing H1 and CTA destinations are preserved. The subtitle and secondary CTA label follow the approved mockup. Search retains its form, accessible label, input and handler immediately below the banner. Other homepage sections are unchanged.

The banner adapts to a single column on phones, with stacked buttons, readable live text and an input that fits narrow screens. The decorative illustration uses empty alt text and 192px/384px transparent WebPs.

Artwork generated using the built-in image generator. Prompt:

Use case: stylized-concept. Production decorative joystick illustration for Teach Arcade homepage hero. Reference image: ONLY option A Classic Marquee joystick at far left is the style and subject reference. Draw ONE isolated compact arcade joystick: bright red round ball handle, short cream metal shaft, chunky dark navy square base in simple three-quarter perspective, thin teal edge trim and one small gold round button. Clean flat arcade illustration with crisp bold navy edges, very restrained two-tone shading, simple readable silhouette, entire object visible with comfortable margins. Transparent background. No banner, no frame, no text, no typography, no stars, no sparkles, no extra objects, no glow, no photo realism, no detailed texture. Palette must work against a deep navy marquee and match classic cabinet navigation tiles.

Validation: full static build, decoded image sizes/alpha, source comparison of unchanged homepage sections and scripts, browser preview for layout, links, image loading, keyboard focus and search behavior.
