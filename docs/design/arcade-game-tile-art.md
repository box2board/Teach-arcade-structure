# Arcade Review Games — Tile Art

The current collection uses [Classic Game Box](arcade-game-box-art.md) styling: black-and-gold packaging with simpler arcade scenes. The notes below describe the previous Flat Arcade set, whose assets remain available.

## Previous Flat Arcade set

All 18 game tiles use the approved Option C Pale Lavender (`#EAE3FA`) background. Each game has its own simple blue/teal/gold illustration with bold navy outlines and generous negative space.

AI-generated transparent source illustrations are exported as 384×256 and 768×512 RGBA WebPs. CSS supplies the exact common background color. Titles, descriptions, game links, grade badges, and controls remain HTML rather than baked into images. Decorative images have empty alt text; existing accessible link names identify each game.

The prompt manifest records the game-to-asset mapping and generation prompts. Changes are limited to the collection page and artwork; individual games are unchanged.
