# Review Lab tile artwork

Approved direction: option A, Pixel Arcade. Eight original covers generated with the built-in image generation tool use 16-bit pixel art, indigo backgrounds, bold silhouettes and teal, blue, orange and gold focal colors. Separate 384×256 and 768×512 WebP files preserve previous artwork. Nearest-neighbor resizing and CSS pixelated rendering keep edges crisp. Prompts are recorded in review-lab-pixel-prompts.json.

Catalog image metadata, hub image rendering and the four fallback cards are updated. A hub-only stylesheet displays complete artwork without cropping. Game descriptions, facts, topic-bank logic, launch links and playable game code are preserved. Images use empty alt text beside their game headings.
