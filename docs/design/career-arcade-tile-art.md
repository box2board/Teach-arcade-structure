# Career Arcade tile artwork

Approved direction: option A, Soft Arcade. Four original illustrations generated with the built-in image generation tool use muted slate blue and teal fills, crisp navy outlines and small warm gold details. CSS supplies powder blue (#E6EFF5). Each image has transparent 384×256 and 768×512 WebP versions. Prompts are in career-arcade-soft-prompts.json.

The hub replaces emoji with decorative artwork and white copy panels. Titles, descriptions, launch URLs, scripts and availability labels are preserved: Career Quest remains live; the other three remain coming soon. No game files change.
