# Brain Arcade — Flat Arcade

Approved Solitaire mockup Option D sets the Warm Peach background (`#FFE7D5`) for Brain Arcade. Simple blue/teal/gold illustrations use bold navy outlines, quiet compositions, and generous negative space.

Each AI-generated transparent source is exported as 384×256 and 768×512 RGBA WebPs. CSS supplies the exact background color. All 22 catalog games receive their own artwork, and the four Popular Games cards reuse the corresponding assets. The homepage's 3D Block Builder tile receives matching artwork as well.

Titles, descriptions, categories, badges, filter behavior, accessible link names, and destinations remain HTML. Decorative artwork has empty alt text. Individual game code is unchanged. The prompt manifest records the generation prompts and asset mappings.
