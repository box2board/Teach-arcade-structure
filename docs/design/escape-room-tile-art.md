# Escape Room tile artwork

Four Flat Arcade illustrations generated with the built-in image generation tool. All use Soft Butter (#FFF2CC) supplied by CSS and transparent 384×256 / 768×512 WebP assets. Prompts are recorded in escape-room-flat-prompts.json.

Only the mission hub cards change. Mission titles, descriptions, tags, launch URLs and playable room files are preserved. Decorative images have empty alt text; card text supplies the mission identity.
