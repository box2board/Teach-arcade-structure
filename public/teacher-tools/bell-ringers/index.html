    How to Use in Class

    Run bell ringers and exit tickets as quick, repeatable routines that build confidence and accountability.

    1. Set a timer and display the prompt.
    2. Students respond independently or in pairs.
    3. Quick share: ask 2–3 students to read answers.
    4. Reveal the key and discuss patterns or misconceptions.
    5. Optional gamify with points, streaks, or team totals.
