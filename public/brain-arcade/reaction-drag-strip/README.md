# Reaction Drag Strip

Reaction Drag Strip is a racing-inspired Brain Arcade reaction-time game.

## How it works
- Press **Start Run** to arm the drag tree.
- Wait for the amber sequence and random delay.
- Press only when green appears.
- Pressing early triggers a **FALSE START**.

## Controls
- **Mouse/Touch:** tap the large press zone.
- **Keyboard:** press **Space** or **Enter**.

## Modes
- **Single Run:** one timed reaction per run.
- **Best of 5:** tracks five attempts, then reports average and best valid run.

## Saved data
- Personal best is saved in `localStorage` by difficulty.
- If storage is blocked, the game still works with session-only stats.
