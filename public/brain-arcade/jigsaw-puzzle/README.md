# Brain Arcade Jigsaw Puzzle

A standalone, browser-only jigsaw game for Brain Arcade.

## Features
- Three original picture choices
- 9, 16, and 36-piece puzzles
- Pointer and touch dragging with forgiving snap-to-place
- Relaxed play or an optional elapsed-time display
- Picture preview, pause, restart, and change-puzzle controls
- Keyboard piece selection and movement

Images are original SVG illustrations stored in `assets/`. Puzzle state remains local to the current play session.
