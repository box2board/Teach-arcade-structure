How to Use the Random Name Picker

  1. Paste or type one student name or item per line.
  2. Press Spin the Wheel.
  3. Use the selected result, then close the winner card or spin again.
  4. For no repeats, turn on Remove selected name after each spin. Use Reset removed to start a fresh round.

Why Use a Random Student Picker?

A random selector can make everyday classroom choices faster and more transparent. It can reduce the tendency to call on the same volunteers, give more students a chance to participate, and add a small moment of anticipation without turning a simple routine into a complicated setup.

Classroom Random Picker FAQ

Is the classroom random name picker free?

Yes. The wheel is free to use and does not require a Teach Arcade account.

Can I paste an entire class list?

Yes. Paste one name per line. Blank lines are automatically ignored, and you can edit the list at any time.

Can I remove students after they are selected?

Yes. Turn on “Remove selected name after each spin.” The Reset removed button restores the full list for a new round.

Can I use the wheel for things other than student names?

Yes. Each line can be a question, vocabulary term, activity, classroom job, group, presentation topic, or any other text entry.

Can I use the random picker on a classroom projector?

Yes. Projector mode enlarges the wheel and removes secondary page content so the active classroom controls stay easy to see.

Are student names uploaded or stored online?

The wheel code processes entries in your browser. Saved class lists use your browser’s local storage on that device, and the wheel does not place roster entries into its URLs.

Can I save more than one class list?

Yes. Open Saved class lists, give the current list a name such as “Period 1,” and save it locally in this browser. You can load or delete saved lists later.

What happens if the same name appears twice?

Duplicate lines are treated as separate entries. If a name appears twice, it has two equal entries on the wheel.

Does the wheel work on phones and tablets?

Yes. The wheel and controls resize for smaller screens while keeping the larger desktop and projector layout for classroom use.
