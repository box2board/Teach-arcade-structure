Free Random Name Picker Wheel for Classrooms, Teams, and Groups

Teach Arcade’s random name picker wheel is a free online wheel of names for choosing one person, team, task, question, or option from a list. Paste or type one entry per line, then click the wheel or press Spin the Wheel. The spinner slows to a stop and clearly displays the selected result.

Teachers can use the name wheel to call on students, assign classroom jobs, choose groups to present, select review questions, rotate stations, or decide who goes first. The same random picker also works for meetings, teams, family decisions, games, and any situation where you want a visible random choice instead of picking by hand.

No account or sign-up is required. The wheel works directly in a modern browser on desktop, Chromebook, tablet, or phone, and Presentation Mode makes it easy to project for a whole class.

How to Use the Wheel of Names

  1. Add your names or choices. Type or paste one entry per line in the list beside the wheel.
  2. Choose your options. Turn on Remove winner after spin if you want a no-repeat order, choose a color palette, and keep confetti on or off.
  3. Spin the wheel. Click the wheel, select Spin the Wheel, or focus the wheel and press Space or Enter.
  4. Use the result. The selected name appears on screen. Continue with the same list or automatically remove the winner before spinning again.

You can also shuffle the list, save it in the current browser, restore it later, or create a share link for the current wheel. If you are projecting the random name picker, use Presentation Mode to give the wheel more screen space.

Random Name Picker for the Classroom

A visible spinner is useful in class because students can see the available names and watch the selection happen. Instead of the teacher deciding who gets called on, the name wheel makes the choice in front of the group.

Common classroom uses include:

  • Randomly call on a student to answer a question.
  • Choose a student or group to present first.
  • Assign classroom jobs, lab roles, or discussion roles.
  • Select a review question, vocabulary word, writing prompt, or problem type.
  • Choose station rotations, teams, topics, or activities.
  • Create a no-repeat participation order by turning on Remove winner after spin.

For a related classroom tool, use the Random Classroom Group Maker when you need to create complete groups or partners instead of selecting one name at a time. You can also pair the wheel with the Classroom Timer for timed responses or activities.

Is the Random Name Wheel Fair?

On a standard spin, every active slice on the wheel has the same chance of being selected. With eight different names, for example, each name occupies one of eight equal slices. Each spin makes a new random selection.

If the same name is entered more than once, that name appears on more than one slice and can therefore be selected more often. If you want equal odds for each person, enter each name once. Turning on Remove winner after spin removes the selected slice, so the next spin chooses from the remaining entries.

The wheel is designed as a quick classroom and group randomizer, not as a tool for regulated lotteries, gambling, or security-sensitive drawings.
