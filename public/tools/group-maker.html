How to Make Classroom Groups

  1. Paste student names, one per line.
  2. Choose Students per group or Number of groups.
  3. Select Generate Groups or Make Pairs.
  4. Copy, print, project, or generate again for a new random mix.

FAQ

How do I split my class into random groups?

Paste the student names, choose students per group or the number of groups, and select Generate Groups. The tool randomly divides the class and can reshuffle the same roster anytime.

Can I make random partners or pairs?

Yes. Select Make Pairs or set Students per group to 2 to create random classroom partners.

Can I choose the group size or number of groups?

Yes. Choose a specific number of students per group or tell the tool exactly how many groups you want.

Can the Group Maker avoid repeat pairings?

Yes. Turn on Avoid prior pairings and record pairings between rounds to reduce repeated student combinations.

Is this random group generator free for teachers?

Yes. It is free to use and does not require an account or login.

Does Teach Arcade save student names?

Names are processed in your browser. The optional Save feature stores the list on that device. A copied share link includes the names currently entered.
