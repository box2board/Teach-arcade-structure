How to Use It

  1. Paste student names, one per line.
  2. Choose students per group or number of groups.
  3. Select Generate Groups or Make Pairs.
  4. Copy, print, project, or generate again.

FAQ

Is this classroom group maker free?

Yes. It is free to use and does not require an account or login.

Can I make random partners?

Yes. Use Make Pairs or set Students per group to 2.

Can I choose the number of groups?

Yes. Choose Number of groups and enter how many groups you want.

Can I regenerate the groups?

Yes. Generate again anytime to reshuffle the same class list.

Does Teach Arcade save student names?

Names are processed in your browser. The optional Save feature stores the list on that device. A copied share link includes the names currently entered.
