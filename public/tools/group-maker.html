Make Classroom Groups in Seconds

This free group maker helps teachers split a class into random groups without sorting names by hand. Use it for quick partners, balanced teams, project groups, labs, discussions, review games, or classroom rotations.

Ways Teachers Can Use the Group Maker

  • Random student groups
  • Partners and pairs
  • Project teams
  • Discussion groups
  • Lab groups
  • Review-game teams
  • Cooperative learning groups
  • Classroom rotations

Why Use a Random Group Generator?

Random grouping saves time, makes the process feel fair, and gives students chances to work with different classmates. When you want more variety across multiple days, the optional pairing-history feature can reduce repeated partnerships.

How to Use the Classroom Group Maker

  1. Enter or paste student names, one per line.
  2. Choose students per group or the number of groups.
  3. Select Generate Groups, or choose Make Pairs.
  4. Copy, print, project, or generate again if you want a new mix.

Classroom Group Maker FAQ

Is this classroom group maker free?

Yes. The Teach Arcade Classroom Group Maker is free to use and does not require an account or login.

Can I create random student groups?

Yes. Paste your class list, choose your grouping settings, and generate randomized student groups in seconds.

Can I use it to make partners?

Yes. Select Make Pairs, or set Students per group to 2.

Can I choose the number of groups?

Yes. Change Create groups by to Number of groups, then enter how many groups you want.

Can I create groups by group size?

Yes. Choose Students per group and enter the group size you want.

Can I use the group maker on a classroom projector?

Yes. After generating groups, use Projector View to enlarge the results on supported browsers.

Does Teach Arcade save student names?

The Group Maker processes names in your browser. The optional Save feature stores the list in local browser storage on that device. Copy Share Link includes the entered names in the link you copy, so do not share a link containing information you consider sensitive.

Can I regenerate the groups?

Yes. Select Generate Groups again to create a new mix using the same class list and settings.
