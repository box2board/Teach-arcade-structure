A FEW QUICK ANSWERS

Made for the school day.

Free classroom timers, random pickers, group makers, and activity tools in one place.

Do I need an account?

No. Open a tool and start using it. Some tools need your names, questions, or settings before you begin.

Can I use these with a projector?

Yes. Open a tool on the computer connected to your display. Tools such as the timer offer a fullscreen option; available controls vary by tool.

Where are my favorites saved?

Favorites and tools opened from this page are remembered in this browser when storage is available. Clearing browser data removes them. This hub does not store student names or class lists.

Which tools can I print?

Start with Graphic Organizers for printable templates, or use the print option in Random Group Maker for classroom groups.
