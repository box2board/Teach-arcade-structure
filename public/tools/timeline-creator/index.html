Classroom ideas & quick help

Build a historical timeline, trace a character’s journey, document an experiment, or tell a life story. Add a caption, explain why each event matters, and include your sources.

Even spacing gives each event room to breathe. True time scale places markers according to elapsed time and stacks nearby cards to avoid overlap. Dragging a card changes its placement, not its date. Edit dates in the event panel.

Click an empty part of the timeline to add an event. Use Focus to expand the workspace. Download PNG for a visual poster, PDF for a poster plus complete notes, or Blank PDF for an empty worksheet. Arrow keys move through presentation slides; Escape closes presentation or focus mode.

Supports years 1–9999 BCE/CE, optional month/day, and event or era date ranges. There is no year zero. Images stay with the saved project. The example uses original illustrative symbols, which you can replace with your own pictures.
